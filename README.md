### Walkable art world (Van Gogh–style pattern)

```text
Using GPT-6 Astra + Three.js, turn a set of paintings or brand stills into a walkable
miniature town. Preserve recognizable motifs, prioritize camera readability, ship one
self-contained HTML demo. Then propose an ad remake variant that keeps my product
visible in the hero walkthrough.
```

---

### Drawing → editable Blender model

```text
Take this line drawing / sketch and build a fully editable Blender model with clear
object hierarchy (aim for hundreds+ of named objects if the reference supports it).
Export stills + a short orbit. Document assumptions. Do not claim clinical/medical accuracy.
```

---

### Photo → personal platformer hero

```text
I uploaded a photo. Make this person the hero of an original platformer with multiple
worlds, distinct enemies/bosses, and a gentle difficulty mode. Deliver a playable
prototype plan (web or iOS) and art direction notes. Do not copy commercial game IP.
```

---

### Lightcycle / arena demo → playable

```text
Render a lightcycle-style arena battle in Blender from a clear cinematic reference,
then port a playable slice to Unreal (or Three.js) that runs on desktop and ideally iOS.
Prioritize feel over feature count. Attribute any music separately; do not bundle
copyrighted audio without a license.
```
